# KanjiForge data attribution

KanjiForge application and pipeline code is MIT licensed. Generated content packs,
deck definitions, and `similar.json` are CC BY-SA 4.0 unless a pack below says
otherwise. This file is intentionally complete and is also suitable for use when a
pack is redistributed without the application. The machine-readable, offline app
catalog is [`attribution.json`](./attribution.json).

The exact pack hashes, sizes, source hashes, license hashes, pinned versions and
all deck filenames are in `attribution.json` and the pack manifests. `JMnedict`,
`KRADFILE/RADKFILE`, and the pinned Noto font are documented below because they
are in the build lock; only the Noto font is used by the similar generator, and no
JMnedict pack is currently shipped.

## Per-source use and modification

- **KANJIDIC2 — © Electronic Dictionary Research and Development Group, Monash University — CC BY-SA 4.0.** Used for kanji reference fields, grades, frequency, readings and meanings, and as deck input. Converted to SQLite and filtered; SKIP and misclassification query fields are deliberately removed.
- **JMdict/JMdict_e — © Electronic Dictionary Research and Development Group, Monash University — CC BY-SA 4.0.** Used for the words-core dictionary and kana deck references. Converted to SQLite/FTS, English fields retained, common-tagged entries selected and `commonScore` derived.
- **JMnedict — © Electronic Dictionary Research and Development Group, Monash University — CC BY-SA 4.0.** Pinned as the optional names source; `npm run build:names` converts it to an indexed SQLite/FTS pack while retaining English descriptions, readings, forms and name-type tags. The optional artifact is not forced into the default install.
- **KRADFILE/RADKFILE — © Electronic Dictionary Research and Development Group, Monash University — CC BY-SA 4.0.** Pinned for radical/component lookup and multi-radical search provenance; represented as source provenance, not as a separate current pack manifest.
- **KanjiVG — © Ulrich Apel — CC BY-SA 3.0.** Used for stroke paths, starts and component trees, and as input to similar-kanji generation. Paths are normalized and re-encoded. Stroke output remains a separate CC BY-SA 3.0 pack.
- **Tatoeba Project — CC BY 2.0 FR.** JA-EN sentences, links and WWWJDIC indices are filtered and ranked; this includes Tanaka Corpus JA-EN examples. The `sentences` SQLite table preserves the upstream Japanese sentence author (`ja_author`) and English translation author (`en_author`) alongside their stable Tatoeba IDs (`id` and `en_sentence_id`), sourced from the pinned `sentences_detailed.csv` export. No share-alike claim is made for the Tatoeba content.
- **JmdictFurigana alignment data — Doublevil; derived from JMdict / EDRDG — CC BY-SA 4.0.** The alignment data maps JMdict writing/reading pairs and carries the corresponding JMdict-derived CC BY-SA attribution and share-alike obligations. The upstream repository's MIT license applies to its code only; it does **not** make the shipped alignment data MIT-only. Alignments are applied to sentence/dictionary forms.
- **JLPT Kanji Data (davidluzgouveia) — MIT; derived from Jonathan Waller's JLPT Resources (tanos.co.uk), CC BY.** Resolved into JLPT kanji deck membership and labeled as an unofficial community estimate.
- **JLPT Vocabulary (yomitan) — CC BY-SA 4.0; derived from Jonathan Waller's JLPT Resources (tanos.co.uk), CC BY.** Resolved into vocabulary deck membership; unresolved entries are recorded in `jlpt-coverage.json`, and deck descriptions say the levels are unofficial.
- **Noto Serif JP — The Noto Project Authors — SIL OFL 1.1.** Pinned generator-only font used for deterministic 64×64 glyph rasterization. Its glyph raster contribution is used to generate `similar`; the font file is not embedded in that JSON pack.
