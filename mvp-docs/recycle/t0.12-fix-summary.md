# T0.12 Fix Summary

## Issues addressed

### 1. CRITICAL — dirty-rect backing buffer never resized
- **File**: `src/prototype/tile-wall/tile-wall.tsx`, `src/prototype/tile-wall/canvas-renderer.ts`
- **What changed**: Added `resizeBackingBuffer()` export; call it inside `applySize()` immediately after setting `canvas.width`/`height` (and before `render`). In renderer, `createRenderer` still inits (small default), but `resizeBackingBuffer` recreates Offscreen + resets `lastOffset*`. Also updated initial path.
- **Why**: Backing was locked at 300x150 forever; dirty pan blitted only tiny patch leaving wall blank after resize/pan. Now matches device size on every container resize.

### 2. HIGH — belt-rank colors invisible at medium zoom (default band)
- **File**: `src/prototype/tile-wall/canvas-renderer.ts`
- **What changed**: Removed `fillRect(0,0,atlas,atlas)` level-0 bg in `buildGlyphAtlas` (canvas starts transparent); changed rebuild guard from `glyphAtlas.width < tile*2` (never true at 1024) to `!glyphAtlas || atlasBuiltForTileSize !== tileSize`; on theme change in `render()` null the atlas+builtSize to force rebuild on next medium render; added `atlasBuiltForTileSize` to state.
- **Why**: Atlas was opaque level-0 overpainting the per-tile level rects (all pixels sampled as #d9d2c3). Glyphs now transparent so level bg shows; atlas now rebuilds on size change + theme (live colors from CSS tokens).

### 3. HIGH — dirty-rect size guard mixes CSS px vs device px
- **File**: `src/prototype/tile-wall/canvas-renderer.ts` (also tile-wall for calls)
- **What changed**: In `renderLowZoom`/`renderMediumZoom`/`getVisible*` call site: compute `logicalW/H = canvas.width / dpr`; use logical for guards, stripX/Y/W/H, fillRect sizes, visible range calcs, and `getVisibleTilesForDOM(..., cssW, cssH)`. Also removed `* dpr` from `getCanvasCoordinates` (now returns CSS units to match offsets/anchors).
- **Why**: panDelta (CSS) compared to canvas.width (device) → guard too loose on DPR>1, wrong strips/ranges. Now all in CSS space (post-scale ctx); anchors/hitTest/DOM positions correct on retina.

### 4. HIGH (perf) — near-threshold dirty-rect more expensive than full repaint
- **File**: `src/prototype/tile-wall/canvas-renderer.ts`
- **What changed**: Replaced simple |delta| < W guard with coverage calc (stripArea union / total); `if (coverage < 0.4 && ...)` then dirty else full. (Threshold ~35-40%.)
- **Why**: Dirty path = 3 full passes (blit + growing strip redraw + copyback) vs 1 for full; large deltas now prefer full (avoids multi-second hangs).

- **Why**: Bursts of 10-20 wheel/pointer events stacked work; now one render per frame. FPS sees real cost.

## T0.12 residual bugs (A/B/C/D) addressed in this pass
### A. CRITICAL residual — dirty-rect blits stale pixels after zoom
- **File**: `src/prototype/tile-wall/canvas-renderer.ts`
- **What changed**: Added `lastTileSize: number` to RendererState (init 32); set `lastTileSize = -1` in `setZoom` and `resizeBackingBuffer`; added `&& tileSize === lastTileSize` guard to `useDirty` calc in `renderLowZoom` (and now also in new dirty path in `renderMediumZoom`); after every paint (full+dirty) in both low/medium, set `state.lastTileSize = tileSize` (alongside lastOffset*).
- **Why**: On zoom change, force full repaint (prevents dirty using backingBuffer holding previous tileSize's painted content/scale). Pan after zoom now only dirties when tileSize matches last.

### B. DPR-safe blit
- **File**: `src/prototype/tile-wall/canvas-renderer.ts`
- **What changed**: In dirty blit (both low+medium): `ctx.save(); ctx.setTransform(1,0,0,1,0,0); ctx.drawImage(backingBuffer, panDeltaX*dpr, panDeltaY*dpr); ctx.restore();` ; for all copy-backs (low dirty/full + medium dirty/full): `backingCtx.setTransform(1,0,0,1,0,0); backingCtx.drawImage(canvas,0,0);` (no save needed on backingCtx). Also enabled full dirty-rect paths in medium zoom (was always-full before).
- **Why**: backingBuffer sized to device pixels (canvas.width/height); main ctx is post-scale(dpr) so user units=CSSpx. Without reset, drawImage misinterpreted image intrinsic size in scaled user space on DPR>1, causing wrong blits.

### C. Wheel `preventDefault` on passive listener
- **File**: `src/prototype/tile-wall/tile-wall.tsx`
- **What changed**: Removed `const handleWheel = useCallback...` and `onWheel={handleWheel}` from <canvas>; added `useEffect(() => { const canvas=...; const fn=(e:WheelEvent)=>{e.preventDefault(); ...zoom...}; canvas.addEventListener('wheel',fn,{passive:false}); return ()=>remove... }, [scheduleRender]); ` (inlined logic, no React.WheelEvent).
- **Why**: React onWheel attaches passive listener (per spec); preventDefault ignored with console warning. Native listener with passive:false allows it.
