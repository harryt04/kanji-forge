# T0.5 Correctness Fixes — Implementor Change Summary

## Issues addressed

### P0 — Component tree must be nested, not flat unique Set
- **File**: `scripts/build-packs/build-strokes-pack.ts`
- **What changed**: Replaced `parseComponentTree` + added `getBalancedInner`, `findGroupEnd`, `parseChildren` helpers. Now recursively walks direct-child `<g kvg:element>` only (using balanced tag depth from string), builds proper `children` arrays; removed `Set` dedupe entirely.
- **Why**: Preserves kvg:element hierarchy (e.g. 本 → 木 → 丨) and allows duplicate element names as separate sibling nodes (e.g. 東 has two 木). Matches review requirement and DATA-SOURCES §3.1.

### P0 — Clear `packs/strokes/` before write
- **File**: `scripts/build-packs/build-strokes-pack.ts`
- **What changed**: In `main()`, after `mkdir`, added readdir + unlink of all `strokes-*.json` + `manifest.json`.
- **Why**: Old chunk schemes (4E00-4E1F etc.) no longer coexist with new (4E00-4FFF etc.). Manifest chunk list now exactly matches files on disk.

### P1 — Deterministic ordering
- **File**: `scripts/build-packs/build-strokes-pack.ts`
- **What changed**: In `groupByUnicodeBlock`, after collect, sort each `strokeList` by `parseInt(codepoint,16)`. In `writeChunks`, iterate using fixed `blockOrder = [...UNICODE_BLOCKS.map... , 'CJK_Extended']`; keys assigned to `data` in that sorted order.
- **Why**: Codepoints sorted; chunks emitted in UNICODE_BLOCKS order; JSON object keys created in sorted sequence (stable for node JSON.stringify + sha256 in manifest).

### P1 — startPoints must stay index-aligned with paths
- **File**: `scripts/build-packs/build-strokes-pack.ts`
- **What changed**: Removed `.filter(Boolean)`; now `paths.map(p => { const pt=extract...; if(!pt) throw...; return pt })`. Also hardened `extractStartPoint` regex to `/[Mm]\s*([\d.-]+)[,\s]+.../` (handles "M ", "m" lowercase relative-first).
- **Why**: Lengths always equal; `startPoints[i]` corresponds to `paths[i]`. Errors now surface (no silent desync). Re-throw in catch so bad files fail build.

### P2 — Assert viewBox is 0 0 109 109
- **File**: `scripts/build-packs/build-strokes-pack.ts`
- **What changed**: In `parseSVG`, after viewBox extract: `if (viewBox !== '0 0 109 109') throw new Error(...)`. (Also rethrow parse errors.)
- **Why**: Enforces the expected box (all current KanjiVG match; will fail build on mismatch or future change). "if easy" item implemented as hard assert.
