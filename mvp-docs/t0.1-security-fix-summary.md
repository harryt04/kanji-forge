## Issues addressed

### HIGH — hardcoded fake licenseHash strings
- **File**: `scripts/build-packs/fetch-sources.ts`
- **What changed**: Added `fetchLicenseText(url)` (with redirect handling), `computeLicenseHash()` that prefers `<id>-license.txt` in `.cache/` then fetches+ caches, `sanitizeForPath()`, host allowlist, and 64-hex validation + assert before any lock write. Removed all placeholder strings (e.g. `'cc-by-sa-4.0-edrdg'`) from `buildSourcesList()`; added `licenseUrl` per source. Added tiny assert `assertPlaceholderRejected` that explicitly rejects fakes + non-hex.
- **Why**: Directly implements real sha256 of license body (from cached or upstream), rejects bad values. Script now generates genuine 64-char hex.

### MEDIUM — EDRDG sources use HTTP not HTTPS
- **File**: `scripts/build-packs/fetch-sources.ts`
- **What changed**: Changed all 5 EDRDG `url` from `http://ftp.edrdg.org/...` to `https://ftp.edrdg.org/...` (and added `www.edrdg.org` to allowlist).
- **Why**: Uses HTTPS as specified; EDRDG supports it.

### LOW — unsanitized upstream release tag/commit names in path.join
- **File**: `scripts/build-packs/fetch-sources.ts`
- **What changed**: Added `sanitizeForPath()` (strips `..`, path seps `/ \`, replaces other chars); applied to `fileName = ${id}-${safePinned}...` before `path.join(CACHE_DIR, ...)`.
- **Why**: Prevents path traversal if upstream tag is malicious.

### LOW — HTTP redirects to any host (no allowlist)
- **File**: `scripts/build-packs/fetch-sources.ts`
- **What changed**: Added `ALLOWED_HOSTS` set + `isAllowedHost()`; applied checks in `fetchJson`, `downloadFile` redirect paths, and new `fetchLicenseText`. Rejects disallowed redirect hosts.
- **Why**: Restricts to known upstreams only.

### LOW/info — JmdictFurigana license "MIT" no audit trail
- **File**: `scripts/build-packs/sources.lock.json` (notes) + `mvp-docs/DATA-SOURCES.md`
- **What changed**: Updated lock `notes` with explicit audit: "JmdictFurigana license recorded as \"MIT\" per the LICENSE file in https://github.com/Doublevil/JmdictFurigana (raw); note that README.md claims \"same licence as JMDict (CC BY-SA)\" -- we use the explicit LICENSE file as authoritative". Updated DATA-SOURCES §4.2 similarly. Also changed script source entry license to 'MIT' + correct licenseUrl. Confirmed by raw LICENSE fetch + hash match.
- **Why**: Provides the required audit trail; kept "MIT" (matches explicit LICENSE, even with README conflict).
