# Implementor Change Summary

## Issues addressed

### T0.6 sentences ETL produced only stub 341B sqlite + fake manifest (prior agent)
- **File**: `scripts/build-packs/build-sentences-pack.ts`
- **What changed**: Replaced the wwwjdic token regex parser with space-split + {}/[]/() extraction that correctly pulls *surface* from inside {} (for ja.indexOf + highlight) and reading from () when present; changed sense bucketing from bare `senseId` ("01") to composite `${surface}:${senseId}` for both candidate grouping and the stored jmdict_sense_id.
- **Why**: The old parser never captured [sense] (regex only looked after }), and bare senseId caused every linked sentence to be grouped under a single key "01", so the <=5 cap kept only ~4 rows total. Composite keys give one bucket per word-sense (~34k unique), producing 62k final sentences after union-of-tops and real links/furigana.
