# C1 analyzer investigation

- Symptom: signed-in `/analyze?text=お金を` stayed on “Preparing preview…” while the browser logged repeated `Gunzip` errors.
- Root cause: Kuromoji’s source entry selected `BrowserDictionaryLoader`, whose `zlibjs` export is undefined in the Next browser bundle; `predev` also omitted the dictionary copy step.
- Fix: development startup now copies IPADIC, production browser loading uses Kuromoji’s bundled browser build, and analyzer failures show one bounded reload message while hiding the preview spinner.
- Evidence: live signed-in Chromium analysis rendered `お金 / おかね / money` and `を`; `npm run ci` passed with 566 unit tests, 18 E2E passes, and all pack checks.
